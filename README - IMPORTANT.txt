ONE CLICK SHUTDOWN FOR WINDOWS 10 / 11
======================================

WHAT IT DOES
------------
Immediately shuts down Windows and force-closes open apps. This prevents the
"Closing apps and shutting down" / "Shut down anyway" screen from stopping the
shutdown.

INSTALL
-------
1. Extract this ZIP file first.
2. Double-click: INSTALL - One Click Shutdown.cmd
3. A shortcut named "One Click Shutdown" will appear on your Desktop and in
   your Start menu.
4. Open that shortcut whenever you want to shut down immediately.

FOR A TRUE SINGLE CLICK
-----------------------
Right-click the new shortcut and choose "Pin to taskbar". You can then shut
down the PC with one click from the taskbar.

REMOVE IT
---------
Double-click: UNINSTALL - One Click Shutdown.cmd

IMPORTANT WARNING
-----------------
The shortcut uses this standard Windows command:

    shutdown.exe /s /f /t 0

The /f option force-closes programs. Save documents, game progress, downloads,
and other work before using it. Unsaved changes can be permanently lost.

No administrator permission is normally required. No files are installed in
Program Files, and no Windows settings or registry entries are changed.
